# Portal JSON parser

Rewritten from `geant-config-generator/tests/geant4/mammo_G4MSBG/parser.py`
(old `gts.BaseParser` API) for the module-level `metadata()`/`parse()` API
that `ci-workflows/validation/export.py` actually calls.

`geant-validation-tests/src/mammo_G4MSBG` only shipped two visualization
macros (`vis.mac`, `vis_HepRep.mac`) — no self-contained validation macro
existed to import as-is. `config.json` selects 4 macros generated by
substituting `geant-config-generator/tests/geant4/mammo_G4MSBG/template.conf`
with 4 of `params.conf`'s `BreastPhantomInferior`/`Superior` rows (depths
0/1/2/3 cm), physics list fixed to `emstandard_opt0`. `params.conf`'s other
4 physics lists (`emstandard_opt3`/`opt4`, `empenelope`, `emlivermore`) are
not included — generate more macros the same way if needed. `NEVENTS` is
kept at `params.conf`'s own value (2×10⁹) for physical fidelity; this may be
far more than practical for a CI run and worth reducing operationally.

Beam particle ("x-ray"/gamma) and energy (20 keV) are hardcoded in
`PrimaryGeneratorAction.cc`, not macro-configurable, so `metadata()` doesn't
read them — `parse()` fills them in as constants, same as the original
parser's `job["PARTICLE"]`/`job["ENERGY"]` (which, in the old system, came
from config-generator's own `!PARTICLE=x-ray`/`!ENERGY=20.` constants, not
from the macro either).

The original parser's `ALIAS` field (`"depth 0cm"` etc.) was a
config-generator templating label, not a macro command, so it doesn't exist
in `commands` here; `BreastPhantomSuperior`'s value (read straight from the
macro) serves the same purpose as the chart's `parameters` tag — the two
happen to carry the same depth value in `params.conf`'s own table.

`read_stdout()` is otherwise unchanged from the original: `x` is the TLD
position index (1-30, as many as the run prints, not merged across the old
job-group averaging — there's only one run per macro now), `y` is dose
scaled from the Monte Carlo air-kerma to the experimental 13.746 mGy
reference and by the 0.808 air→TLD mass energy-absorption coefficient ratio
(NIST, 20 keV), `yerr` from the printed relative uncertainty.
